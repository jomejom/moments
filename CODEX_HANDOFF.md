# Codex handoff — Moment

You are working on an existing Next.js prototype. **Do not re-scaffold or discard existing functionality.**

## Product intent
Moment is a low-pressure journaling companion. The differentiator is a personalized follow-up from Phrug based on a user's earlier reflection. It avoids daily streaks, guilt, and blank-page friction.

## Current scope
The working source includes Today, Memories, localStorage, user-directed revisit tags, fictional demo content, and Phrug's transparent keyword-template follow-ups. There is no LLM or backend, by design. Read README.md before changing code.

## Your tasks
1. Run `npm install`, `npm run lint`, and `npm run build`; fix any errors.
2. Start the app locally and visually inspect desktop and mobile layouts.
3. Manually test: create/save/reload, read entries, select revisit, switch follow-ups, dismiss a topic, delete an entry, and demo entries.
4. Fix bugs without introducing sign-in or paid dependencies.
5. Improve accessibility (keyboard, contrast, labels) and responsive polish.
6. Keep README honest about what is implemented and not validated.
7. Propose next experiment for contextual vs generic follow-up prompt acceptance; do not claim measured retention.

Do not add an AI API unless separately requested. Do not commit secrets or personal journals. Report specific files changed and tests actually run.
